# VGtaps Studio

Distribuição oficial do VGtaps Studio para Windows x64. Este repositório contém somente documentação e arquivos públicos de instalação/atualização. O código-fonte é mantido em repositório privado.

## Instalação e atualização

- [Releases e instaladores](https://github.com/lucakassab/vgtaps-studio-releases/releases/latest).
- A partir da versão7.0.2, use **Buscar atualizações** dentro do Studio. Confira as novidades, escolha **Baixar e atualizar** e depois **Reiniciar e instalar**.
- Downloads e instalações exigem sua escolha. Fechar o Studio normalmente não instala a atualização.
- Projetos, configurações, licenças, chaves, BuildKit e exports são preservados. O BuildKit não acompanha nem é substituído por estes instaladores.
- Instalações portáteis7.0.1 precisam receber o pacote de transição7.0.2 na mesma pasta uma vez. O Setup para instalação nova não transfere automaticamente dados de outra pasta.

## Arquivos de cada release

Instalador NSIS x64 (`.exe`), blockmap, `latest.yml` e `SHA256SUMS.txt`. Os metadados são usados pelo atualizador integrado. Não é necessário baixar esses metadados manualmente para utilizar o Studio.

Canal estável: versões de teste e downgrades não são oferecidos.
